# أذكاري (Adhkari)

موقع ثابت (HTML/CSS/JS) بدون أي مكتبات أو خادم.

## التشغيل
- افتح `index.html` في المتصفح مباشرة، أو استخدم إضافة Live Server في VS Code.
- الخطوط (Amiri وCairo) تُحمَّل من Google Fonts، فتحتاج اتصالًا في أول تشغيل.

## الملفات
- `js/data.js`: بيانات الأذكار والتسبيحات (عدّل المحتوى من هنا).
- `js/app.js`: الواجهة والعدادات وحفظ التقدم (LocalStorage).
- `css/style.css`: التصميم.

راجع نصوص الأذكار وتخريجها قبل النشر.
